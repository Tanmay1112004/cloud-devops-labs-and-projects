# Learning roadmap

Track each lab honestly: `Not started`, `In progress`, or `Verified`.

## Phase 1 — Foundations
- [ ] Linux navigation, files, permissions, users/groups
- [ ] Processes, services, logs, disks, packages, SSH
- [ ] IP, CIDR, DNS, routing, HTTP/HTTPS, ports
- [ ] Bash fundamentals and safe scripting
- [ ] Git commits, branches, merges, pull requests

## Phase 2 — AWS foundations
- [ ] IAM users/roles/policies, MFA, least privilege
- [ ] EC2, AMIs, EBS, snapshots, user data
- [ ] S3, versioning, lifecycle, bucket access
- [ ] VPC, subnets, route tables, IGW, NAT, SGs, NACLs
- [ ] ALB, target groups, Auto Scaling
- [ ] RDS MySQL, backups, restore
- [ ] CloudWatch metrics/logs/alarms, CloudTrail, SNS
- [ ] Route 53, Lambda, DynamoDB, Elastic Beanstalk
- [ ] AWS CLI, Systems Manager, billing/cost basics

## Phase 3 — Containers and IaC
- [ ] Docker images, containers, ports, volumes, networks
- [ ] Dockerfiles, Compose, health checks, image scanning
- [ ] Terraform providers, variables, outputs, state, modules
- [ ] CloudFormation templates, parameters, outputs, change sets

## Phase 4 — Delivery and orchestration
- [ ] GitHub Actions workflow and CI checks
- [ ] Jenkins pipeline fundamentals
- [ ] Kubernetes Pods, Deployments, Services, ConfigMaps, Secrets
- [ ] Probes, resources, persistent storage, ingress

## Phase 5 — Operations and capstones
- [ ] Ansible inventory, playbooks, roles
- [ ] Prometheus metrics and Grafana dashboards
- [ ] Logs, alerts, incident notes, backup/restore tests
- [ ] End-to-end project with deployment, monitoring, security, and cleanup
