# How to add a lab or project

1. Choose the correct technology folder and difficulty.
2. Create a dedicated project folder using a clear, lowercase name.
3. Add a README using the project template in `docs/PROJECT_TEMPLATE.md`.
4. Add architecture source and screenshots where relevant.
5. Test every command from a clean starting state.
6. Document common errors and how to verify the fix.
7. Include cleanup and cost guidance for cloud resources.
8. Check `git status` and inspect files before committing. Never commit secrets.
